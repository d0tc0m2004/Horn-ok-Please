# FLOW STATE: INDIA

## Overview
Skill-based Driving / Survival / Flow Game set in the chaotic traffic of India.
This is not a racing sim. It's about reading intent, anticipating mistakes, maintaining flow, and negotiating chaos.

## Core Pillars
*   **Negotiated Chaos**: Traffic is not random; it's a negotiation.
*   **Flow**: Speed is secondary to constant, fluid movement.
*   **Archetypes**: Diverse NPC behaviors (Aggressive Biker, Passive Scooter, Auto Rickshaw, etc.).

## Development Roadmap
1.  **Bike Feel Prototype**: Physics, steering, leaning, momentum.
2.  **Core Gameplay Loop**: Infinite road generation, traffic spawning, rigorous flow mechanic.
3.  **NPC Logic**: "Belief-based" AI.
4.  **Polish**: Audio, Visuals, Juice.
